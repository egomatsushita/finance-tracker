Finance Tracker frontend — a [Next.js](https://nextjs.org) (App Router, TypeScript, Tailwind v4) dashboard for the Finance Tracker API, bootstrapped with [`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app).

## Getting Started

1. Copy the env example and point it at your running backend:

   ```bash
   cp .env.local.example .env.local
   ```

2. Install dependencies and run the dev server:

   ```bash
   npm install
   npm run dev
   ```

3. Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

4. Visit [http://localhost:3000/design](http://localhost:3000/design) to see the color tokens and typography scale (IBM Plex Sans/Mono) used throughout the app.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to load IBM Plex Sans and IBM Plex Mono.
